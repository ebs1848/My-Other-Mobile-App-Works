# My Other Mobile App Works

A collection of native Android apps written in Java with Android Studio, built while learning mobile development. Each folder is a standalone Android Studio project.

## Projects

| Project | Description |
| --- | --- |
| **Calculator** | A calculator app with digit buttons and arithmetic operations. |
| **CounterTwo** | A counter app with a button that updates two counters. |
| **QRandBarcodeScanner** | A QR code and barcode scanner built with Google ML Kit barcode scanning. |
| **TourGuide** / **TourGuideV2** | A city guide app: pick a city from a list and browse information about it across several screens. |
| **Week1** | A first-week course project built from the Android Studio fragment navigation template. |

## How to run

Open a project folder in Android Studio, let Gradle sync, and run it on an emulator or a connected device.
